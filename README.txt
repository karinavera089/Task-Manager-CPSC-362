Pinned Tasks
Having daily tasks are hard to keep track of and here is where our app comes in to help users with their tasks.  
Our program focuses on the daily tasks a user has and refreshes daily so it can be a quick and easy way to keep daily activities. 
There is a fun interactive background which makes it look as if the sticky notes are pinned onto a corkboard, this makes it so that 
the UX design looks good.This program is currently running as pinnedtasks.netlify.app

FEATURES
Priority levels: This program allows you to set your sticky note via priority levels that are color coded. For high priority notes, they are color coded red, medium priority has yellow notes, and the low priority notes are green color coded. 
Status filtering: There is also a filtering system that filters tasks by status either showing all, finished, unfinished or even priority status.
Statistics: You can also see the constant stats of total notes, completed, and pending tasks to ensure you see the amount of tasks you have left.
Create: As a regular to do list, you are able to create new tasks where you are also asked to choose the priority level of the task and once you click pin note it will appear on your corkboard. 
Delete: If there is a task that you want to remove completely, the user is able to completely delete the whole note and it will be forever deleted.
Update: The program also allows for users to update/edit their task. You can do so by clicking on the small pencil image icon that is on the sticky note and it will allow you to edit the text box where you input the text. 
 Clear all notes: The program also allows for you to clear all the notes on the dashboard by clicking on the upper right hand corner that states that it will clear all the notes. Before clearing the notes the program is set to confirm before deleting all the notes.
